# City Briefing: Power BI Project

Generated by `build_pbip.py` from the `Design v2` assets (re-run it to rebuild).

## Open it
1. Use **Power BI Desktop (Windows)**, current version.
2. Download the `CityBriefing` folder and `../washington_crimes_clean.csv`.
3. Double-click `CityBriefing/CityBriefing.pbip`.
4. **Home > Transform data > Edit parameters**, set `DataPath` to the full path of `washington_crimes_clean.csv`, then **Refresh**.
5. The model's tables load on refresh, and then every visual fills in.

## What's inside
- `CityBriefing.SemanticModel`: fact table, Date/Hour/Weekday/Metric tables, 3 relationships, 19 measures (TMDL).
- `CityBriefing.Report`: 3 pages (Brief, Where, When), a custom theme, page backgrounds, and page navigation buttons (PBIR).
